# KAIP VALDYTI · DI mokytojams · KŠIC Zoom

Kaip televizorius su pulteliu: **kompiuteris rodo**, **telefonas yra pultelis**, **mokytojų telefonai yra balsavimo mygtukai**.

```
[ Kompiuteris: deck'as ] ──Zoom──> 100-500 mokytojų
        ▲   │
  pultas│   └─QR──> mokytojų telefonai (join.html) ──atsakymai──> deck'as
 [ Jūsų telefonas ]
```

## 0 · Rytą: GO

Peržiūrėkite ir parašykite **GO**. Tik tada Neuron daro `git push` ir QR nuorodos pradeda veikti (be push jos rodo 404).

## 1 · 15:20 · Atidarykite deck'ą

Chrome, įklijuokite:
```
https://krisvas333.github.io/bc-day/it-mokytojai-di/index.html?room=KAUN
```
- Viršuje turi būti žalias ženklelis **📱 0 · KAUN**.
- Paspauskite **F** (pilnas ekranas).
- 20 min. versija: pridėkite `&trukme=20`. Atgal į 30 min.: `&trukme=30`.

## 2 · Pultas telefone

1. Kompiuteryje spauskite **?**
2. Telefonu nuskenuokite QR („Telefono pultas").
3. Pultas turi rodyti **GIRDI**.
4. Užrašus skaitykite **tik pulte**. Klavišas N rodo užrašus visam Zoom'ui.

## 3 · Išvalykite bandymus

**Shift+X** du kartus per 3 s. Visi bandomieji atsakymai dingsta, grįžta į 1 skaidrę.

## 4 · 15:25 · Zoom

1. **Share Screen** → pasirinkite **Chrome langą** (ne visą ekraną).
2. Patikrinkite, kad QR matosi dideliu.
3. 15:30 spauskite **0** ir **Enter**: laikrodis žino „pradėjom dabar".

## Klavišai

| Klavišas | Ką daro |
|---|---|
| → arba tarpas | toliau |
| ← | atgal |
| F | pilnas ekranas |
| ? | pagalba + pulto QR |
| T | laikmatis |
| Q | QR: auto / slėpti / visur |
| M | įvesti skaičius ranka (iš Zoom pokalbio) |
| K | „Mentoriui" faktai šiai skaidrei |
| 1-9 + Enter | šokti į skaidrę |
| 0 + Enter | laikrodis „pradėjom dabar" |
| B | judėjimo pertrauka 2 min. |
| Esc | uždaro langą; pertraukos priminimą paslepia 60 min. |
| Shift+R ×2 | išvalyti šio klausimo atsakymus |
| Shift+X ×2 | atstatyti viską |
| N | užrašai (⚠️ matosi Zoom'e) |

## Jei kas nors lūžta

- **Ženklelis raudonas:** sakykite „atsakome Zoom pokalbyje", skaičius įveskite su **M**.
- **Telefonai rodo sąrašą:** viskas gerai, tai atsarginis režimas. Atsakymai vis tiek ateina.
- **Deck'as užšalo:** perkraukite puslapį (F5). Atsakymai išlieka.
